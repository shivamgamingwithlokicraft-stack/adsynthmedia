# adsynthmedia

A high-end, fully functional e-commerce prototype for **adsynthmedia**, built with vanilla HTML5, CSS3, and modern ES6+ JavaScript. 

## Features
- **SPA Routing**: Instant page transitions (Ladies, Men, Divided, Kids, Home).
- **Product Detail Pages (PDP)**: Full product views with image, description, and size selector.
- **Fully Functional Cart**: Add items to the bag, update the cart counter, and calculate totals.
- **Favourites System**: Click the heart icon to save items to a dedicated Favorites page.
- **Size Chart Modal**: Interactive measurement guide.
- **Responsive Design**: Optimized for desktop, tablet, and mobile displays.
